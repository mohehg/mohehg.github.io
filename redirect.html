Website maken: hoofdvraag

Hoofdvraag: Welke stappen en keuzes zijn belangrijk bij het maken van een eenvoudige website voor een gekozen doelgroep?


1. Stel de doelgroep vast. Dit kun bepalen door jezelf deze vraag te stellen: voor wie maak ik deze website en waarom?


2. Zoeken naar de programmeertalen die je moet gebruiken om een simpele website zoals deze te maken. Voor deze website hebben wij HTML, CSS en JavaScript gebruikt.

3. Bepalen hoe je je website gaat inrichten voor je gekozen doelgroep. Als je bijvoorbeeld een website gaat maken waar je snoep verkoopt, is het handig om een kleurige achtergrond te gebruiken.

4.Dit is de laatste stap hier bepaal je de lettertypes en lettergrootte met CSS. Je bepaalt wat wat is met HTML en met JavaScript bepaal je bijvoorbeeld om een menu uit te klappen en werkende knoppen te maken.
