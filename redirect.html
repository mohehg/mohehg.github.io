Website maken: Introductie

Als allereerst, wij hebben deze website gemaakt met deze hoofdvraag en deelvragen die we nu gaan beantwoorden. Wij hebben een hoofdvraag en een paar deelvragen bedacht.

We gaan de hoofdvraag samen met jullie langs en zullen hem zo goed mogelijk beantwoorden.

Onze eerste hoofdvraag is welke stappen en keuzes belangrijk zijn bij het maken van een eenvoudige website voor een gekozen doelgroep.
Dit is eenvoudig te beantwoorden met de volgende stappen:
1. Stel de doelgroep vast. Dit kun bepalen door jezelf deze vraag te stellen: voor wie maak ik deze website en waarom? 2. Zoeken naar de programmeertalen die je moet gebruiken om een simpele website zoals deze te maken. Voor deze website hebben wij HTML, CSS en JavaScript gebruikt. 3. Bepalen hoe je je website gaat inrichten voor je gekozen doelgroep. Als je bijvoorbeeld een website gaat maken waar je snoep verkoopt, is het handig om een kleurige achtergrond te gebruiken. 4.Dit is de laatste stap hier bepaal je de lettertypes en lettergrootte met CSS. Je bepaalt wat wat is met HTML en met JavaScript bepaal je bijvoorbeeld om een menu uit te klappen en werkende knoppen te maken.
