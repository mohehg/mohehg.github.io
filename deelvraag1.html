Deelvraag 1: Welke programmeertalen en tools worden vaak gebruikt bij het maken van een simpele website?


Met HTML kan je de structuur en inhoud van een website maken. Je kan bijvoorbeeld met HTML typen op je website of bijvoorbeeld knoppen toevoegen.


Met CSS kun je de opmaak van je website maken. Je kan bijvoorbeeld de lettertypes en lettergrootte bepalen met CSS.


Met JavaScript kan je de functionaliteit van je website maken. Je kan bijvoorbeeld een menu uitklappen of werkende knoppen maken met JavaScript, zoals we eerder zeiden.


Met deze drie programmeertalen kan je een simpele website maken zoals deze.
