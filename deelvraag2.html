Deelvraag 2: Hoe bepaal je de doelgroep van je website en hoe moet je website eruitzien als je je doelgroep hebt gekozen?


Om de doelgroep van je website te bepalen moet je jezelf afvragen voor wie je de website maakt en waarom.


Als je de doelgroep van je website hebt bepaald moet je jezelf afvragen hoe je de website eruit wilt laten zien. Je kunt bijvoorbeeld een website maken die er professioneel uitziet of juist een website die er speels uitziet. Het is belangrijk dat de website aansluit bij de doelgroep.


Als je de doelgroep van je website hebt bepaald en je weet hoe je de website eruit wilt laten zien kun je beginnen met het maken van de website. Je kunt bijvoorbeeld een website maken met HTML, CSS en JavaScript of je kunt een website maken met een website builder zoals oDoo of WordPress.
